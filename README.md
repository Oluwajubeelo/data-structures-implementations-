# 🎓 CSC 341: Data Structures Implementation

This repo contains the implementation of the data structures and algorithms treated in our class. All the members of Group 8 contributed to this repo. Implementations have been fully commented and documented.


## 🚀 How to Run the Algorithms

Every implementation includes a built-in demo. You can run any algorithm directly from the terminal to see it in action:


```bash

# the format is "python [name of file].py"

# Run the AVL Tree implementation
python avl.py

# Run the Linked List demonstration
python linkedlists.py
```
